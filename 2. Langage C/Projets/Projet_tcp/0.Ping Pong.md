# Ping Pong

## Cahier des charges
|tache|description|
|-|-|
|Le client doit envoyer la string "ping" au serveur||
|Le client doit reçevoir la string "pong" du serveur||

## Pré-requis
- File Descriptor
- Struct
- Socket TCP
- Faire un client tcp : socket,bind,connect,send,recv
- Faire un serveur TCP : socket,bind,listen,accept,send,recv
